# Order Processing REST API

## Overview

The Order Processing REST API is a Java backend application developed using Spring Boot and Maven.

The application provides RESTful endpoints for managing retail orders while following a layered architecture that separates business logic, data access, and API functionality.

## Features

- Create Orders
- Retrieve Orders
- Update Orders
- Delete Orders
- RESTful API Design
- Exception Handling
- Service Layer Implementation
- Repository Pattern
- Maven Project Structure

## Technologies Used

- Java
- Spring Boot
- REST API
- Maven
- Apache Tomcat
- JSON
- MVC Architecture
